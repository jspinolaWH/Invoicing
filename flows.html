/ralph fixes code-level gaps — missing endpoints, entities, business logic. Does not inspect UI.
/ralph-brother fixes UI-level gaps using ui-check reports as its spec, with a /gap-check pre-flight to catch missing backend before the frontend tries to call it.
They can safely run in parallel: /ralph owns ralph/gaps/ exclusively; /ralph-brother reads those files only after its own /gap-check step writes them fresh.

Files produced
ralph/prd.json
Source of truth. All skills read and write flags: passes, ui_mapped, ui_partial, ui_no_frontend, needs_review.
ralph/gaps/PD-XXX.md
Code gap report per requirement. Written by /gap-check. Merged with UI gaps and rewritten by /ralph-brother Step 2.
ralph/ui/[domain]/PD-XXX.md
UI flow report. Written by /ui-check. Read by /ralph-brother Step 2 for UI synthesis.
ralph/ui/ui-coverage-summary.md
Full coverage table and orphan audit. Written by /ui-loop after all ui-checks complete.
ralph/loop.log
Append-only event log for /ralph. Never overwritten.
ralph/loop-summary.md
Final pass / needs-review / failing summary written by /ralph on completion.
ralph/ui/ui-loop.log
Append-only event log shared by /ui-loop and /ralph-brother.
ralph/ui/brother-summary.md
Final UI fix summary written by /ralph-brother on completion.
